# Model 4 – Weighted Ensemble

## Objective

Improve MCQ answer ranking by combining the strengths of multiple independently trained models through weighted probability averaging.

## Base Models

- Model 1: TF-IDF + LightGBM Learning-to-Rank
- Model 2: DeBERTa-v3 Multiple Choice Transformer
- Model 3: Retrieval-Augmented Generation (RAG) + LightGBM Ranker

## Ensemble Strategy

The final prediction is obtained by computing a weighted average of the class probabilities generated by each base model.

### Ensemble Weights

| Model | Weight |
|-------|-------:|
| Model 1 | 0.35 |
| Model 2 | 0.20 |
| Model 3 | 0.45 |

The combined probability distribution is ranked to obtain the Top-3 answer choices required by the competition.

## Methodology

- Collect probability distributions from all three models.
- Apply weighted averaging.
- Rank answer options based on final probabilities.
- Generate Top-3 predictions.
- Export the final Kaggle submission.

## Advantages

- Combines complementary strengths of classical ML, transformer models, and retrieval-based ranking.
- Produces more robust predictions than relying on a single model.
- Reduces variance by aggregating multiple independent predictors.
